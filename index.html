关于科瑞斯

南京科瑞斯软件科技有限公司成立于 2019 年，位于南京市江北新区，是一家专注于提供工业自动化技术及汽车电子领域装配及测试解决方案的供应商，能够为客户提供优质的服务和技术支持，快速响应客户的需求。

公司成员均来自非标自动化行业，拥有丰富的自动化装配线设计与测试台开发经验，业务覆盖电气自动化、机械设计与制造、上位机软件设计、汽车电子测试服务、工业机器人系统集成与离线仿真。

DCT Transmission · End of Line

DCT 变速箱 EOL 测试台

针对双离合器变速箱下线测试，台架采集 Oil In / Oil Out 油路、NVH Sensor、Input Drive 与 Output Drive 1/2、Park Lock 等部位信号；模拟量 / 数字量经 Drive Control 以 100Hz 采样，TCU 相关信号通过 CAN Cyclic 周期读取。

  • 100Hz 采样：Input/Output 模拟数字信号、扭矩信号
  • Load Cell：Parking Lock Force 锁止力测量
  • Encoder：Parking Lock Position 锁止位置计数
  • CAN Cyclic：转速、主油路 / 离合器压力与电流位置
  • 换挡测试：Shift Rod 电流与位置 1-4 挡、多电流值 GU1+GU2
  • 状态监测：当前 / 目标挡位、变速箱状态、油液与离合器温度

Body Control Module · Function Test

车身控制器 BGM 功能测试台

测试对象为车身控制器 BGM。作为乘用车上的主节点，其功能复杂、实时性要求高，还需要具备功能安全特性。测试台需要仿真 CAN、LIN、FlexRay 总线，以及基于车载以太网的 DoIP 诊断与 Flash 刷写功能。

  • 多总线仿真：CAN、LIN、FlexRay 残余总线同步仿真
  • 车载以太网：DoIP 诊断通讯
  • Flash 刷写：控制器程序烧录与校验
  • 功能安全：测试步骤、期望值与测量值自动判定
  • 工装设计：测试台正视结构、探针与指示灯布局
  • 流程编排：上电、释放、写配置、诊断与恢复全流程

Turbocharger · Reliability Bench

涡轮增压器测试系统

测试对象为涡轮增压器：将其放置于密闭实验室内并连接到燃烧器，台架对油温、油压、水温以及流量在不同工况下进行控制，通过热老化和热冲击来验证涡轮增压器的可靠性和性能参数。

  • 燃烧系统：400kW 燃烧室、天然气与空气冷却干燥单元
  • 热管理：油温 / 油压 / 水温 / 流量多工况闭环控制
  • 可靠性验证：热老化（Thermal Aging）与热冲击（Thermal Shock）
  • 特性标定：Map Mapping Editor 压气机特性曲线绘制
  • 加速度测量：Acceleration measurement 振动监测
  • 参数表：流量、压比、效率、转速数据管理
